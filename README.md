# 拾念 · 灵感收件箱

随手存下一个念头，在新内容里找回旧灵感。手机与电脑网页均可使用，可在支持的浏览器添加到主屏幕。

**在线使用：从仓库的 Deployments 或 Pages 入口打开已发布网页。版本：0.2.0。**

这是网页应用（PWA），不是微信原生小程序。

## 这一版可以做什么

- 记录文字，保留原话，编辑标题、标签、关键词、下一步与来源链接；搜索、归档与恢复。
- 连接使用者自己的 Chat Completions 兼容模型服务。提供公共服务及本机服务的地址格式模板；选择模板不会发送请求。
- 可记住地址和模型名称。密钥只在当前页面内存中使用；刷新后，密钥与自动调用授权都会清除。
- 连续保存的卡片进入串行整理队列，显示等待、处理中、失败、取消和未完成状态；失败后由使用者决定是否重试。
- 用词语、同义表达规则和已保存关键词寻找旧卡片；可以主动允许更广的模型候选范围。关联建议必须由使用者逐条确认。
- 保存最近八次标题、标签、关键词、下一步等修改前的版本，可撤销最近一次修改；原话和已确认关联保留。
- “再想一想”在本地选出最多三张值得回看的卡片，可以继续推进、标记下一步完成或七天后再看。
- 导出、合并 JSON 备份；升级时读取 0.1 的旧卡片与关联，不自动重发未完成请求。
- 缓存应用文件以支持离线记录。发现新版后提示更新，未保存输入、编辑或模型任务存在时暂停切换。

## 依赖与发布

应用没有第三方运行依赖，不加载外部字体、CDN、统计脚本或模型 SDK，也不需要数据库服务。

| 环节 | 依赖 | 提供者 |
| --- | --- | --- |
| 记录、本地关联、回顾 | 现代浏览器 | 使用者 |
| 网页发布 | GitHub Pages、官方 GitHub Actions | 仓库维护者 |
| AI 整理 | 兼容模型接口、额度及浏览器访问许可 | 每位使用者自己 |
| 开发与单元测试 | Node.js 22 或更高版本 | 开发者 |

发布流程固定官方 action 的提交版本，不执行 npm install，仅上传 `site/`。测试、备份、运行检查结果和本地配置不会随网页发布。

公开源文件不包含维护者的个人模型接口、密钥、姓名或邮箱。经维护者授权，代码提交可使用其本机配置的 Git 身份，姓名和邮箱会在提交记录中公开。GitHub 还会显示仓库所属账号，重写提交历史也不能保证平台缓存中的旧对象已删除；公开托管不等于平台层面的匿名。

## 连接自己的模型

点击“连接我的模型”，选择模板或填写完整地址，例如 `https://your-model-service.example/v1/chat/completions`，再填服务支持的模型 ID 和自己的密钥。该地址是格式示例，不是可用服务。免密服务可以留空。

模板仅帮助填写格式，不保证模型名称、额度、浏览器跨域访问或本机权限可用。支持的是非流式 Chat Completions 兼容协议；其他协议需要使用者自己的兼容网关。

“保存并测试”只发送固定测试文字，不发送卡片，可能产生少量费用。仅保存连接不会自动测试。自动整理需主动勾选，刷新后需重新授权。

密钥不写入 localStorage、sessionStorage、JSON 备份或仓库。“记住地址和模型名称”默认关闭，主动勾选后持久偏好只包含地址、模型名称、模板与扩大候选范围的选择，不含密钥或自动调用授权。“忘记配置”清除这些偏好和本页连接。浏览器扩展、密码管理器和设备本身不在应用控制范围内。

模型请求只发送到使用者配置的服务，不带网站 Cookie，不发送网页来源引用，拒绝重定向，拒绝 URL 中的用户名、密码、查询参数或锚点。本项目没有公共转发服务，不代收模型密钥。浏览器应用运行时必然能够使用输入的凭据，使用者应选择信任的版本、服务与限额密钥。

服务必须允许网页跨域访问（CORS），包括本站来源、POST、Content-Type 和 Authorization。浏览器不能总是区分网络、跨域、地址或本机访问限制，页面会保留这种不确定性。错误提示不展示服务返回的错误正文。接口不允许浏览器访问时，可使用自己的可信网关，或复制请求到常用 AI 软件再粘贴 JSON 结果。

远程地址必须使用 HTTPS。本机 `localhost`、`127.0.0.1` 或 `::1` 可使用 HTTP，仍受浏览器安全策略及本机服务配置限制。

## 模型能看到哪些内容

默认不开启自动 AI 整理。主动调用时，普通范围发送当前原话和最多三张按本地词语匹配找到的旧卡片片段。勾选扩大范围后，最多八张候选由同义规则、关键词和近期卡片补充选出。每张旧卡片片段最多 1400 字符，输入数据 JSON 总计不超过 18000 字符。手动发送前可查看本次完整请求。

模型结果检查请求 ID、卡片 ID、结构、卡片是否已变化，以及关联引用是否来自本次实际发送的片段。它更新标题、标签、关键词和下一步，不改写原话。手动调用返回后还需确认保存；主动开启自动整理后可以自动更新这些字段，所有关联仍需逐条确认。

串行队列不会暗中重试。支持 Web Locks 的浏览器还会协调同站点的多个窗口。每次最多输出约 2500 tokens，客户端等待 60 秒。取消或超时不保证模型服务停止计费。刷新后本窗口的未完成任务被标记为中断；其他已关闭窗口的遗留任务可以手动标记，再决定是否重试。

本地规则可能漏掉相关卡片或推荐无关卡片。引用检查也不代表模型判断、事实或因果关系正确。可以拒绝任何建议。

## 数据、回顾与范围

卡片、修改记录和回顾状态保存在当前浏览器 localStorage，没有跨设备同步。回顾选择完全在本地进行，不调用模型；优先考虑未完成下一步、新确认的联系和较久未看的卡片。完成回顾后至少一天不重复推荐，选择稍后再看则暂停七天。

JSON 备份包含卡片、修改记录、任务与回顾状态，不包含模型连接偏好或密钥。合并时已有同 ID 卡片保留当前版本，导入的未完成任务不会自动调用。浏览器清理数据、无痕模式退出或更换设备可能丢失记录，请定期导出备份。

设计上限为 3000 张卡片和 10000 条确认关联，实际受浏览器存储额度限制。写入失败会提示；损坏存储会停止写入以保护原始内容，可先导出原始存储。网站宿主方有其自身访问日志，应用不承诺所有网络活动匿名。

本版不抓取网页正文、不后台监控、不读取其他 AI 软件的登录状态、不提供语音转写或云端同步。语音记录可以使用手机键盘自带输入。

## 本地运行与验证

```sh
node scripts/serve.mjs
node --test
node scripts/evaluate-associations.mjs
node scripts/privacy-check.mjs
```

本地访问 `http://127.0.0.1:4173/`，服务器默认只监听本机。也可用静态服务器托管 `site/`；不要双击 HTML，ES 模块与服务工作线程需要 HTTP(S)。

浏览器检查脚本 `scripts/browser-check.mjs` 和 `scripts/browser-check-v02.mjs` 使用开发者已有的 Playwright，通过 `PLAYWRIGHT_MODULE` 指定模块路径。它不是网页运行依赖。检查使用虚构地址和模拟响应，不调用维护者或使用者的真实模型服务。

关联比较保留二十条人工标注的开发样例及失败明细。这些样例用于调规则，属于开发校准，不能作为独立验证、真实用户效果或完整语义检索的证明。真实模型的端到端可用性及一周使用体验尚未验证。

隐私检查只输出是否发现问题与文件位置，不打印用于匹配的个人身份或密钥。它覆盖当前源文件和可达提交历史，不能证明托管平台缓存已清除。

仓库 Settings → Pages 选择 GitHub Actions，推送 main 后运行单元测试并发布网页。
